# Proyecto 1

Autor: Raybel Martínez

Fase1 prepara usuarios de ejemplo; Fase2 valida credenciales; Fase3 añade PIN por Telegram; Fase4 añade sesiones. Ejecuta las fases de servidor de una en una, pues usan el puerto 3000. Consulta el README de cada fase.

Necesita MongoDB y, para enviar PIN, un bot de Telegram propio. No se publicaron credenciales ni se enviaron mensajes.
